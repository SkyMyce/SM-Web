Requirements

The SkyMyce JAR already contains Fabric API and SkyblockPV. You install Fabric Loader and Fabric Language Kotlin yourself.

  • MC
    Minecraft {{requirements.minecraft}}The exact version. Other versions will not load the mod.
    Required
  • J
    Java {{requirements.java}}Most launchers bundle it. In Prism or MultiMC, pick a Java {{requirements.java}} runtime for the instance.
    Required
  • FL
    Fabric Loader {{requirements.fabricLoader}} or newerInstall with the Fabric installer or your launcher.
    Required
  • K
    Fabric Language KotlinNot bundled. Download the build for Minecraft {{requirements.minecraft}} and put it in the same mods folder. This is the dependency people miss most.
    Install separately
  • API
    Fabric API {{requirements.fabricApi}} or newerBundled inside the SkyMyce JAR. If you also install it yourself, use this version or newer.
    Bundled
  • PV
    SkyblockPV {{requirements.skyblockPv}} or newerBundled inside the SkyMyce JAR. If you already have SkyblockPV installed, it must be {{requirements.skyblockPv}} or newer.
    Bundled

Install

  1. Install Fabric for Minecraft {{requirements.minecraft}} with the Fabric installer or your launcher.
  2. Close Minecraft.
  3. Open the mods folder. Press Win+R, paste the path below and press Enter. Launchers like Prism use the instance's own mods folder instead.
    %appdata%\.minecraft\mods
  4. Add both JARs: the SkyMyce JAR and Fabric Language Kotlin.
  5. Launch with the Fabric profile and type /sm.

Migrating from the old Loader?

SkyMyce no longer needs its own Loader. Remove the old SkyMyce Loader JAR and the old mod JAR from your mods folder, then install the current release as above. Keep your other mods and settings.

Verify your download

Each release is described by a manifest signed with Ed25519 (key {{signing.keyId}}). When this page can reach the release service it checks that signature in your browser and shows the expected SHA-256 above. The in-game updater performs the same check before staging an update.

Run the command in the folder that holds the download, then compare the file's hash with the SHA-256 shown above or on the GitHub release:

Windows (PowerShell)

Get-FileHash -Algorithm SHA256 .\Sky*.jar

macOS

shasum -a 256 [Ss]ky*.jar

Linux

sha256sum [Ss]ky*.jar

If the hashes differ, delete the file and download it again from this page or GitHub. Do not run JARs shared in chats or by other players.

The release file keeps its historical name, Sky-Myce-<version>.jar.
