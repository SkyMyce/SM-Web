From download to /sm in four steps.

The whole install is two files in one folder. The one people miss is Fabric Language Kotlin.

  1. Install Fabric for Minecraft {{requirements.minecraft}}.

    1
    • Fabric Loader {{requirements.fabricLoader}} or newer
    • Java {{requirements.java}}

    Use the Fabric installer or your launcher's Fabric profile. Most launchers bundle Java; in Prism or MultiMC pick a Java {{requirements.java}} runtime for the instance.

    Install and troubleshooting guide

  2. Put two JARs in your mods folder.

    2
    • The SkyMyce JAR
    • Fabric Language Kotlin

    Fabric API and SkyblockPV are already inside the SkyMyce JAR. Fabric Language Kotlin is not, and a missing copy is the most common reason the game won't start.

    %appdata%\.minecraft\mods

  3. Launch and type the command.

    3
    • Works on any server
    • No account needed

    Start Minecraft with the Fabric profile, join a server and open the menu. Search finds any setting by name.

    /sm

  4. Turn on only what you use.

    4
    • Every feature is a switch
    • Local by default

    Nothing is forced on. Flip the switches you want, move widgets with /sm hud, and connect Discord only if you want chat, leaderboards or shared cosmetics.

Short answers. Real ones.

Does SkyMyce play for me?

No. It reads menus, chat and what your client can see, and tells you what to do next. Clicks, confirmations and movement are yours.

Is it allowed on Hypixel?

SkyMyce is not affiliated with Hypixel or Mojang. You are responsible for following Hypixel's rules on client modifications. If you are unsure about a feature, leave it off.

Do I need Discord?

No. Every local feature works without it. Discord is only needed for Global Chat, community leaderboards, sharing cosmetics and signed updates.

What data does it share?

No community data is shared until you connect Discord. After that, one setting, Community data sharing, decides: On, On (anon) (the default) or Off. See Privacy for every category.

Which mods do I need with it?

Fabric Loader and Fabric Language Kotlin. Fabric API and SkyblockPV are bundled. See Install and troubleshooting.
