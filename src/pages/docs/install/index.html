Install step by step

  1. Install Fabric for Minecraft {{requirements.minecraft}}.
  2. Download SkyMyce from the download page and Fabric Language Kotlin for {{requirements.minecraft}}.
  3. Close Minecraft.
  4. Put both JARs into the mods folder of the instance you play with.
  5. Start the game with the Fabric profile and type /sm.

Mods folder locations

Windows:

%appdata%\.minecraft\mods

macOS:

~/Library/Application Support/minecraft/mods

Linux:

~/.minecraft/mods

Launchers such as Prism, MultiMC and Modrinth App give each instance its own folder. Use the launcher's "Open mods folder" or "Open instance folder" action instead of the paths above.

Migrating from the old Loader

Earlier versions shipped with a separate SkyMyce Loader. It is no longer needed. Remove both the old Loader JAR and the old mod JAR, then install the current release normally. Keep your other mods and settings.

Troubleshooting

Fabric reports that SkyMyce needs fabric-language-kotlin

Fabric Language Kotlin is missing. Download the build for Minecraft {{requirements.minecraft}} and put it next to SkyMyce. This is the most common error.

Wrong Minecraft or Fabric version

Fabric names the version it expected. Make sure the instance runs Minecraft {{requirements.minecraft}} and Fabric Loader {{requirements.fabricLoader}} or newer.

A Java version error at launch

The game is running on an older Java. Select a Java {{requirements.java}} runtime for the instance in your launcher.

Conflict with SkyblockPV

SkyMyce bundles SkyblockPV. If you also installed SkyblockPV yourself, it must be {{requirements.skyblockPv}} or newer; otherwise remove your copy or update it.

/sm does nothing

Check the JAR is in the mods folder of the instance you actually launched, and that the game started with Fabric. The title screen's Mods list should include SkyMyce.

A community feature says it is unavailable

Open /sm community and check the connection. Local features never depend on it, so everything else keeps working.

Reporting a problem

Include the SkyMyce version, Minecraft version and the relevant part of logs/latest.log from your instance folder. Remove account names, tokens or other private information first. Report it on GitHub Issues.

Uninstall

Delete the SkyMyce JAR from your mods folder. Settings and local history stay in config/skymyce inside your instance folder; delete that folder too if you want them gone. To remove community data, disconnect and turn sharing off first; see Privacy.
