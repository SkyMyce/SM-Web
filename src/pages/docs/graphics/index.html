Graphics modes

The graphics mode sets how much effort SkyMyce's menus spend on effects, including GUI animations.

ModeUse it when
Extremely LightYour frame rate struggles; menus are as simple as possible and animations are off
LightYou want fewer effects and simple transitions
MediumYou want a balance of polish and speed
HighYou want every effect and full GUI animations

What is never reduced

HUD information, dungeon tracking, routes and the Crush Camera keep working the same in every mode, and Minecraft's own video settings are not changed.

Performance tips

  • Turn off features you don't use; each one is a separate switch.
  • If menus feel slow, try a lighter graphics mode before anything else.
  • Report a performance problem with your SkyMyce version, mode and logs/latest.log.
