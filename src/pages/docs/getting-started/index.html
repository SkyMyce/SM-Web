Before you start

You need Minecraft {{requirements.minecraft}} with Fabric, Java {{requirements.java}}, and Fabric Language Kotlin next to the SkyMyce JAR in your mods folder. The install guide covers each step; the download page has the file.

Open the menu

Join any server and type:

/sm

/skymyce does the same. You can also bind a key to open the menu under Settings → Controls.

The menu has six areas:

  • Dungeons: parties, routes, rewards, run history and the boss tools.
  • Combat: ability timers, status bars, loadout keys and instance helpers.
  • Economy: the auction browser, price history and stash filter.
  • Cosmetics: your name, size and cape.
  • Utils: Daily Digest, Global Chat, leaderboards, overlays and inventory helpers.
  • Settings: Discord and community, appearance, HUD layout and controls.

Find any setting

Use Search at the top of the menu. It matches feature names, setting names and common words (try "pb", "keybind" or "reroll") and tolerates a small typo. Quick Settings, Favorites and Recent give you shortcuts to the things you change most.

Five good first switches

  1. Dungeon Tracker (Dungeons → Runs). Records runs and loot from now on.
  2. Dungeon Chests (Dungeons → Rewards). Profit estimates and reroll protection.
  3. Party Finder (Dungeons → Parties). Set your floor, classes and PB limit.
  4. Status Bars (Combat → Player). Off by default; arrange them with /sm bars.
  5. Daily Digest (Utils → Progress). Open it any time with /sm digest.

Arrange the HUD

Widgets such as the tracker and skill XP can be dragged, scaled, anchored and reset in the HUD editor:

/sm hud

Pick a theme preset under Settings → Appearance. Every menu and widget follows it.

Local first, community optional

Everything above works without a Discord account. Global Chat, community leaderboards, cosmetics sharing and signed updates are optional and need a Discord link; see Community & Discord.
