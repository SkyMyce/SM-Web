How it knows what is happening

It combines three things:

  • what your client sees: chat lines, your own terminal windows and loaded player positions;
  • short smt1: updates that other SkyMyce users post in party chat;
  • the selected strategy profile.

It never clicks, moves or leaps for you. Party chat is its only transport; the SkyMyce relay is not used.

Set it up

  1. Turn on Dungeons → Boss → Goldor Coordination. The strategy is Gold standard by default.
  2. Add the Goldor Map widget in the HUD editor (/sm hud).
  3. In a run, check the state at any time with /sm goldor.

Read your class's full steps in chat:

Profiles

  • Gold standard (default): the baseline above, for F7 and M7.
  • Gold standard, Archer EE2: the same baseline for parties where Archer runs EE2. Only the EE2 runner and the S1 leap target change.
  • SkyMyce ADG: the default before 2.7.26. It differs from the baseline in S1 order, Berserker's S2 order (T4 then T3) and the S3 device stack.

Gates and the Goldor tick

The map moves to the next section when Goldor's gate line appears once a section is complete. If no line appears, it switches six seconds after the last completion. The Goldor tick (every three seconds through the phase) is tracked so pre-leap timings line up.

Fixing the state

  • /sm goldor role <player> <class> sets a teammate's class; /sm goldor unrole <player> clears it.
  • /sm goldor section <s1|s2|s3|s4|core> corrects the current section.
  • /sm goldor learned shows learned teammate roles; add reset to clear them.
