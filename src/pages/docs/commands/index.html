Goldor

CommandWhat it does
/sm goldorCurrent Goldor status
/sm goldor guide [class] [section]Step guide, for example /sm goldor guide mage s2
/sm goldor ifList every condition with its current value and how it is known
/sm goldor if <condition> <yes|no|clear>Confirm or clear a condition for this run
/sm goldor role <player> <class>Set a teammate's class manually
/sm goldor unrole <player>Clear a manual class
/sm goldor section <s1|s2|s3|s4|core>Correct the current section
/sm goldor learned [reset]Show or clear learned teammate roles

Chat and community

CommandWhat it does
/sm communityManage the Discord connection, data sharing and updates
/sm irc, /sm globalOpen Global Chat
/sm irc <message>Send one Global Chat message
/sm msg <ign> <message>Send a private relay message
/sm reply <message>, /sm r <message>Reply to the last private message
/sm chat <ign>Route normal chat to a friend
/sm chatStop routing and return to normal chat
/sm helpChat help
/sm cosmeticsOpen Cosmetics Studio
/sm cosmetics linkOpen Cosmetics Studio on the linking step

Party chat is unavailable. /sm party and /sm pc exist but are rejected, because the community service cannot verify current Hypixel party membership. Party Finder tools are separate and work normally.

A few commands (ircaction, lfgreply, relaymsg, ircstatus, irccancel) are used by clickable chat buttons and are not meant to be typed.
