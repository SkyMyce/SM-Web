Connect Discord

  1. Run /sm community (or open Settings → Community) and choose to connect.
  2. A browser page from the SkyMyce relay names the Minecraft account you are connecting. Continue only if you started the request in game.
  3. Discord asks you to authorize SkyMyce with the identify scope: your Discord ID and name, nothing else.
  4. When the page says "Discord connected", return to Minecraft.

If the browser flow isn't available, the mod shows a one-time code you can give to the SkyMyce Discord bot instead.

Your game proves your Minecraft identity to the relay each time it connects; the relay never sees your Minecraft password or Microsoft login.

Community data sharing

One setting decides what you contribute, with three modes:

ModeWhat happens
OnShares dungeon stats, RNG drops, activity and leaderboard contributions, and shows your Minecraft name on public reports.
On (anon), the defaultShares the same categories, but your name is replaced by "Anonymous player".
OffStops all sharing. Earlier contributions are removed or suppressed.

Chat and cosmetics keep their own identities and are not affected by this setting. The full list of what each category contains is on the privacy page.

Global Chat

Open it with /sm irc, or send one message with /sm irc <message>. Global Chat is bridged with the SkyMyce Discord's global channel, so Discord members see your messages and you see theirs.

  • Reply to and react to messages; edit or delete your own from the message controls.
  • Images, GIFs and videos from links show as previews.
  • Messages are live only: there is no scroll-back history when you join.
  • Sending is rate limited; repeated identical messages are rejected for a short time.

Party chat (/sm party) is unavailable, because the service cannot verify current Hypixel party membership.

Private messages

  • /sm msg <ign> <message> sends a private relay message.
  • /sm r <message> replies to the last one.
  • /sm chat <ign> routes normal chat to that friend until you run /sm chat or switch Hypixel chat channels. Check the selected mode before you send.

Signed updates

Automatic updates are Off by default. In /sm community, Update Now checks for a new release, verifies its Ed25519-signed manifest and the file's SHA-256, and stages it; restart Minecraft to apply. If community services are unavailable, your installed mod and local features continue to work.

Disconnect

Disconnect in /sm community. You can also manage the link from Discord with the SkyMyce bot's account commands (status, unlink a Minecraft account, disconnect). To remove what you shared, set Community data sharing to Off before or after disconnecting.

On the website

The community hub shows leaderboards, a read-only view of Global Chat and shared cosmetics. Website sign-in and live data need relay changes that are not deployed yet, so these pages currently show clearly labelled preview data.
